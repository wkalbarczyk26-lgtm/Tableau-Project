# 📊 Tableau Retail & Sales Dashboard Project

## 📌 Project Overview

This project was completed as part of a **Data Technician Bootcamp** and focuses on using **Tableau** to analyse and visualise **retail and sales data**. The main objective was to transform raw data into **interactive dashboards** that clearly communicate insights and support data-driven decision-making.

The project places strong emphasis on **data storytelling**, ensuring insights are easy to understand for both technical and non-technical audiences.

---

## 🛠️ Skills & Tools Used

### 📈 Data Visualisation in Tableau

* Designed a range of charts to explore and present data, including:

  * **Bar charts** for category and product comparisons
  * **Line charts** to show sales trends over time
  * **Pie charts** for proportion and contribution analysis
  * **Maps** to visualise sales performance by location

---

### 🎛️ Interactivity & Dashboard Design

* Built **interactive dashboards** combining multiple visualisations
* Used **filters and slicers** to allow users to:

  * Explore data by time period, product, or region
  * Drill down into specific areas of interest
* Designed dashboards with a clear layout and logical flow for usability

---

### 🧮 Calculated Fields

* Created **calculated fields** to:

  * Derive new metrics
  * Support deeper analysis of sales and performance
  * Enhance insights beyond the original dataset

---

## 📂 Dataset

* Retail and sales data including:

  * Dates and time periods
  * Products and categories
  * Geographic information
  * Sales and performance metrics

The data was structured to support both exploratory analysis and dashboard creation.

---

## 🎯 Key Outcomes

* Developed strong Tableau dashboard-building skills
* Gained experience in **visual storytelling** using data
* Improved ability to communicate insights clearly through interactive visuals
* Demonstrated practical skills relevant to entry-level data and analytics roles
